# Comparing campaigns, and clicks

For comparing campaigns or reading clicks from a campaign's links. One campaign's results, or a Bolta routine: [campaigns-and-routines](results-campaigns-and-routines.md).

## Comparing campaigns

- Few went out: say where it stopped, not that the strategy failed.
- First run of a strategy: too early to drop it. The first run had the thinnest context.
- Two campaigns teach something only if they differ in one thing, ideally the strategy.
- Never add campaigns together: one post can sit in two. Overlap and side-by-side: bolta.ai/dashboard/analytics > Campaigns.

## Clicks

Links go out exactly as written: Bolta adds no tracking tags and never sees a click, so never state a click count or promise tagged links. To see clicks in their own site analytics, the user gives links that already carry their own `utm_` tags.

## Always

- Follow the house rules in the Bolta skill.
