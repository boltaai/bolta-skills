# Formatting and links

Part of [media](post-media.md). Bolta facts for how a post's text is shown when it goes out.

## Formatting

- Reddit, Discord and WordPress show Markdown as written. On the other social networks Bolta turns it into plain text when it posts:
  - bold, italic and headings become look-alike bold or italic letters,
  - a link becomes "words (address)",
  - `-`, `*` and `+` list items become • bullets; numbered lists stay as typed,
  - quote markers and divider lines are removed; table rows keep their `|` pipes.
- So write plain text with line breaks. Skip headings and tables; use bold rarely, since look-alike letters don't read well for everyone.
- `get-posting-rules` has notes on formatting, links and extra parts for each network. Trust it over this page, except its link-tracking note (see Links).

## Links

- Use only links the user gave.
- Links point where the user wrote them, with one exception: on Threads everything after a `?` or `#` in a link is removed, tracking tags included.
- When it goes out, Bolta swaps each link for a short tracked bolta.ai link to the same page, tagged with the post and its campaign; a link's own `utm_` tags are kept. Clicks show in the Bolta dashboard, never through these tools: never state a count. Cross-posting an article: put its public URL in every post.

## Always

- Write plain text with line breaks for every network but Reddit, Discord and WordPress.
- Use only links the user gave; never promise tracking.
