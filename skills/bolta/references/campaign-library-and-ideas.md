# The employee Library and the idea bank

Read when someone asks about posts employees share as themselves, "Make it mine", or which files Bolta reads for ideas. Campaign formats and a team version: [formats-and-team.md](campaign-formats-and-team.md).

## The employee Library

Approved posts employees share as themselves from a private link, managed in Brand > Library (bolta.ai/dashboard/knowledge-base?tab=library). Say it plainly: "Your team gets a link with ready posts they can share as themselves."

- **Filling:** Bolta writes up to 20 Library posts a run, 3 runs a day. Each waits in Approvals first. Approved there, it goes live on the link; if "send to client" was chosen, it goes to the brand's client reviewers instead, and their approval puts it live. Credits are charged only when a post is approved, never for writing it.
- **Adding a post:** "Add to Library" in an approved or published post's menu puts it on the link at once, with no second review: it was reviewed once.
- **The share link:** turned on, off or replaced there.
- **"Make it mine":** an employee's rewrite in their own voice, on the brand's credits, with daily limits per link.
- A routine can add Library posts each run: [routine-outputs.md](routine-outputs.md). Deciding Library rows in Approvals: [review-more-decisions.md](review-more-decisions.md).

These tools can't fill the Library or change its link: send the user to Brand > Library, or to Bolta's own chat (bolta.ai/dashboard/hub).

## The idea bank

Files under Sources (bolta.ai/dashboard/knowledge-base?tab=references), such as a deck, a transcript or a report, are read for specific ideas, one per post, for campaigns, routines and the Library. A file is read only once one of those writes from the brand: a big import with no active routine, campaign or Library waits. The plan caps files read a day, so many files take days; only the start of a very long file is read, and a file with almost no text is skipped. A file attached to an active campaign ([targets.md](campaign-targets.md)) goes first.

Say it as: "Bolta reads your files for ideas, a few a day, and each post takes one."

## Always

- Send Library work to Bolta's own pages; never claim I did it.
- Never say a file was read before a routine, campaign or the Library writes from it.
- Follow the house rules in the Bolta skill.
