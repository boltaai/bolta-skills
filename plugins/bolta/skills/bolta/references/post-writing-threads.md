# Post: writing for Threads

After [the voice, line by line](post-writing-voice.md), for any Threads post. A conversation feed (500 characters a post): each post is one remark to a regular, not an announcement.

- **Short:** 1-3 sentences, one idea. No headline, list or bold.
- **Conversational:** plain spoken words, contractions, "we" and "you". The first words are the point (the product and what it tastes, smells or does), not a label.
- **No link or website in the text** unless the user asks; Bolta strips tracking tags from Threads links ([Threads settings](post-settings-threads.md)).
- **No hashtag in the text** unless the voice wants one; a topic is a setting (`topic_tag`), offered, not written in.
- **A question or reply hook only if it fits the voice** (curious or playful) and only about the reader's own taste ("Which would you try first?"). One, at the end, never on every post, never needing a fact the record lacks.
- Each post stands alone. Several parts only when the user asks for a thread.
