# The one next step

Read after the honest read, to pick the single next step. Offer one, never a menu.

- **After a winner:** offer one more like it now ([post](post.md)): "Make 3 more like the winner?" Or "keep doing this" with a Bolta routine: `repurpose_top_posts` or `thread_from_top_post` ([routine](routine.md)).
- **"When should I post?"** Offer the `best_time_to_post_report` Bolta routine ([routine](routine.md)).
- **One campaign:** verdict, then "Run it again with the same strategy?" if it worked, else "Try <another strategy> next?" Finishing it: [campaign](campaign.md).
- **Low decision rate:** suggest fewer posts a week, not a new strategy.
- **Drafts still waiting:** send them to [review](review.md).
- **A flop pattern** (one network, format or topic far below the rest over two windows, on synced posts): offer one change to the Bolta routine that writes them, such as fewer posts there or a different topic, shown before and after, saved only on a yes ([routine](routine.md)).
- **A disconnected account** behind missing numbers: reconnect first ([connect](connect.md)); nothing else is worth changing until it syncs.
- **"Send me this every week":** the `performance_digest` Bolta routine ([routine](routine.md)).
- Worked: [last-week-results](../examples/last-week-results.json).

## Always

- Follow the house rules in the Bolta skill.
