# Plain words

Use these in everything the user reads. Left of the colon: Bolta's data. Right: what to say.

## Words to use

- Draft: draft, "saved, not going out".
- Pending Approval, the inbox, the Approve tab: waiting for your yes, in your review list.
- approve: say yes, or approve.
- Scheduled: scheduled, always with the time: "Wed Oct 21, 9:00 am (New York)". Work the weekday out from the date; never copy one from an example.
- approve_only: approve, and Bolta picks the time (your next posting-schedule slot, when you have a schedule).
- use_suggested_time: Bolta's suggested time for that draft.
- Published / Partially Published / Failed: went out / went out on 2 of 3 accounts / didn't go out, because...
- Quality Blocked: held back, needs a human edit.
- Rejected: turned down.
- Routine: Bolta routine on first mention, "work Bolta repeats for you". Never a bare "routine" where the app's own scheduling could be meant.
- App scheduled task: weekly scheduled task.
- Content Campaign: campaign. The only name; never "push".
- Calendar campaign label: calendar tag. Keyword monitor: conversations Bolta watches for you. Never "campaign" for either.
- strategy_key: strategy, by the dashboard's name with a short gloss ("Problem / Solution: a real frustration, then the fix").
- content_mix: posts a week, by kind ("3 images and 1 carousel a week").
- duration_weeks: how many weeks.
- Campaign status draft / scheduled / active / paused / completed / archived: not started / starts on its date / on / paused / finished / retired.
- Campaign state needs_accounts / needs_review / scheduled / generating / posting / done: needs accounts / waiting for you / next drafts on a date / writing drafts now / posting / finished.
- approval_policy review_every_artifact / inherit / auto: ask me first / use my workspace setting / post without asking (if the workspace allows it).
- Voice Profile, Voice DNA: your voice.
- Business DNA, Workspace Brief: about your business.
- Knowledge base: your documents.
- feedback_count: "learned from N of your decisions".
- bucket: account group.
- token_status invalid: disconnected, with a reconnect link. ghost: not connected yet (never "broken").
- Routine display_state on_track / waiting / running / blocked / failed / paused: on track / drafts waiting for you / writing now / can't run / last run failed / paused. pause_reason plan_gate, trial_quota: your plan or credits; disconnected_source: an account needs reconnecting; user_requested: you paused it.
- Safe Mode: review mode ("Safe Mode" in settings, said once).
- AI credits: uses credits.
- hunter, outreach, engagement opportunity: reply drafts, conversations to join.
- stale_review: "This post changed since you looked. Here's the new version. Still yes?"
- denied_by role / workspace_plan / key_scope / override: your role can't / your plan doesn't include it / this connection lacks that access / an admin turned it off for you.

## Never say

MCP, tool, OAuth, connector, fingerprint, artifact, workflow definition, source binding, template key, capability keys, cursor, beat, producer, preflight, Hub, Hype-Man, Hunter, Engager, Essence Capture, HTTP codes, or "in Bolta" as a phrase the user must type. No ids, tool names or error codes.
