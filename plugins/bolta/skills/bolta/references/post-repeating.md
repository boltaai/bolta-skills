# The same post, again

When someone wants one finished post to go out more than once, rather than new posts. Fresh drafts on a schedule are a Bolta [routine](routine.md); this page is for repeating or re-sharing what already exists.

## The same post repeating

- Daily, weekly, or on chosen weekdays: the Loops page, bolta.ai/dashboard/calendar/loops. No tool sets it up from here; point them there.
- Loop copies are created as Scheduled and skip review, so they are not for brands that need sign-off on every post. They keep the post's network settings.
- If they want a new post each time, not a copy, say so: "That's a routine: Bolta writes a fresh draft each time and waits for your yes." Then [routine](routine.md).

## Auto-repost and auto-plug

- Only if asked. Both are set in the composer's Schedule dialog in Bolta, not from here.
- Both skip review and drop the post's network settings.
- A plug is a new post, not a reply to the original.

## Always

- Never promise to set up repeating, auto-repost or auto-plug from here: point to the page in Bolta.
- Say that copies skip review before the user turns one on.
- A new post each time is a routine, not a repeat.
